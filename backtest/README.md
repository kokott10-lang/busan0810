# 📈 주식 백테스트 (초안)

FinanceDataReader(시세) + backtesting.py(엔진) + Flask(웹 화면)로 만든 국내 주식 백테스트 도구입니다.
브라우저에서 **종목을 검색**하고, 전략과 기간을 골라 과거 성과를 확인할 수 있습니다.

## 실행

```bash
cd backtest
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

브라우저에서 <http://localhost:5000> 접속.

## 기능

- **종목 검색**: 종목명 또는 코드(예: `현대차`, `005380`). 방향키·Enter로 선택
  - 종목 목록은 FinanceDataReader → (실패 시) pykrx 순서로 불러옵니다.
  - 목록을 못 불러와도 6자리 종목코드를 직접 입력하면 백테스트할 수 있습니다.
- **전략**
  | 전략 | 내용 |
  |---|---|
  | 분할 익절 + 추적 손절 | 시작일 매수 → +1차% 일부, +2차% 일부 익절 → 1차 익절 후 고점 대비 -추적% 전량 매도, 진입가 대비 -손절% 전량 매도. 재진입 옵션: 청산 후 골든크로스 시 재매수 |
  | 이동평균 골든/데드크로스 | 단기 이평이 장기 이평을 상향 돌파 시 매수, 하향 돌파 시 매도 |
  | RSI 역추세 | RSI가 과매도선을 위로 넘으면 매수, 과매수선 이상이면 매도 |
  | 매수 후 보유 | 비교 기준선 |
- **결과**: 수익률·단순 보유 대비·연환산·MDD·승률·샤프 지수, 자산 곡선(단순 보유와 비교), 거래 내역, backtesting.py 상세 차트(캔들·매매 시점·지표)

## 새 전략 추가하기

1. `app.py`에 `Strategy`를 상속한 클래스를 만들고, 조절할 값은 클래스 변수로 선언
2. `STRATEGIES` 딕셔너리에 등록
3. `templates/index.html`의 `STRATS`와 `<select id="strategy">`에 같은 이름으로 추가

## 주의

- 거래비용은 편도 기준입니다(기본 0.1% → 왕복 약 0.2%. 매도 시 거래세 포함 근사치).
- 주문은 신호가 나온 **다음 날 시가**에 체결됩니다(backtesting.py 기본 동작).
- 수정주가 여부, 배당 미반영 등으로 실제 수익과 차이가 날 수 있습니다. 과최적화에 주의하세요.
- 이 도구는 학습·연구용이며 투자 권유가 아닙니다.
